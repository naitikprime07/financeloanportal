# FinanceLoan Website

Finance news and business insights platform built with React and Vite.

## Setup

```bash
npm install
```

## Development

```bash
npm run dev
```

Visit http://localhost:5173

## Build

```bash
npm run build
```

## Configuration

Copy `.env.example` to `.env` and add your ad configuration:

```env
VITE_ADSENSE_CLIENT_ID=your-client-id
VITE_AD_TOP=your-ad-slot-id
VITE_AD_MIDDLE_1=your-ad-slot-id
VITE_AD_MIDDLE_2=your-ad-slot-id
VITE_AD_MIDDLE_3=your-ad-slot-id
VITE_AD_BOTTOM=your-ad-slot-id
```
